# WISS Stundenplan 1.12.1

This version brings the local demo account to Chrome/Edge, Firefox, Android and iPhone/Safari.

- Try it without a WISS login: "Demokonto testen" (Try demo account) during setup.
- Invented week, exams, grades, absences and room bookings, in the same data format as before.
- The demo never overwrites an existing account; device sync stays off in the demo.
- "Demo beenden" (End demo) removes the invented data and demo notes.
- The mobile adapters support switching to the demo account and removing the demo data for good.
- Drawing the bundled logo now uses the existing DOM parser function instead of setting innerHTML directly.
- Chrome Web Store ZIP without the development key; store pictures, German description and publishing notes are included.

## Downloads
- Chrome/Edge: `WISS-Stundenplan-Chrome.zip` (unzip and load as a local extension; the same ZIP works for the Chrome Web Store).
- Firefox: `WISS-Stundenplan-Firefox.xpi` (signed by Mozilla). The Firefox ZIP is only the upload/source package for Mozilla.
- Android: `WISS-Stundenplan.apk`. Version 1.12.1 / versionCode 11201, signed with the same certificate as 1.12.0, so it installs as an update.
- iPhone/Safari: `WISS-Stundenplan.user.js` for the Userscripts extension.
- `Chrome-Web-Store-Assets.zip`: screenshots, promo tiles, icon, description, privacy policy and instructions.
- `SHA256SUMS.txt`: checksums of the packages.

## Testing
Android release build and signature check passed; the signing certificate matches 1.12.0. Browser tests for Android and iPhone check the demo, all views, local notes, the sync lock and removing the demo for good. The existing cross-platform sync browser test checks opt-in, linking, encryption, merging and deletion. Signing in with a real WISS account and a physical iPhone were not tested for this build.
